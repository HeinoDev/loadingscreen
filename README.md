## Config

Edit `web/public/config.js`:

- `serverName`: shown as typed
- `brand`: `"logo"` or `"name"`, only one is shown
- `keybind`: `false` hides the ENTER prompt and joins as soon as the server is ready

Images: `web/public/hero/01.webp` to `x.webp`.

## Build

```bash
cd web
bun install
bun run build
```
